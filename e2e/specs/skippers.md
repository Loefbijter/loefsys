# Skippers

**As a member, I want to see who can skipper which boats, so that I can ask someone to
go sailing.**

- **SKIP-1** Skippers are grouped under their highest skippership only (someone with
  Kielboot 1 and 2 appears once, under Kielboot 2). The page is reached from "Over ons".
- **SKIP-2** A skipper's profile opens from the overview.
- **SKIP-3** The overview is only for logged-in members.
